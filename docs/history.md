# これまでの依頼と決めたこと（ver.51 まで）

いまの仕様の中心は `CLAUDE.md`。ここは「なぜそうなっているか」をさかのぼるためのメモ。

## 全体

- Excel（原価計算.xlsm）から Web アプリに移した。最初は Claude のアーティファクトだったが、Claude にログインしなくても使えるように GitHub Pages ＋ Dropbox 保存にした。
- ブロックワーク（20分＝1ブロックの週の生産計画アプリ）と原価計算を1つのアプリにまとめた。
- 原材料マスタは Excel の「原価表」から約750品を一度だけ取り込んだ。購入業者・価格更新日は空欄が多く、価格を見直すときに少しずつ埋めていく。
- 表示名は設定で変えられる（いまは「工房ノート」）。

## 商品の情報の分け方

- 商品は1つの情報。原価計算側で、商品番号・1倍の出来高・カテゴリ・材料・資材を入れる。ブロックワーク側で、工程と時間などの仕事の進め方を入れる。
- 商品番号は原価計算でだけ入力する。番号がある商品は、ブロックワーク側では商品名・単位・カテゴリ・出来高を表示だけにする。
- 工程時間は、トモヒロさんのぶんだけを拾う（従業員・パートまで入れると式が複雑になるため）。工賃の単価は店の平均にして、金額のつじつまを合わせる。
- 仕込みを2倍にしても、時間は2倍にならない。設定の「倍数を増やしたときの時間の伸び」で調整する（既定0.3）。
- 工程の「1倍あたり」は仕込み倍数に比例する時間。焼き上がり個数には掛けない（以前これを掛けて、原価が何十倍にもなっていた）。

## 原価計算

- 画面は ①仕込み全体 → ②1包装あたりの資材・仕上げ → 原価計算書。工程チップは「製造／仕上げ」の切り替え（ver.34）。
- 使用可能倍数は×1〜×8と任意（横一列）。原価の基準にする倍数を選べる。
- 製造間接費は「工程の時間 × 設定の単価」で自動で出す。単価の分母は、年間の延べ製造時間（全員ぶん）。
- 設定の「人件費と製造時間の内訳」（人ごとの時給 × 年間製造時間）から、平均の工賃単価を出す。
- 仕掛品（サブレの生地など）には販管費・販売価格を出さない。ほかの商品の①の材料に入れると、原価で組み込む（ver.38）。①に入れた仕掛品は、ブロックワークの「使うもの」に自動で入る（ver.48）。
- ギフト（ver.36〜）：①の「焼き菓子｜ギフト」タブ。中身は登録済み商品かグループ。中身の入れ方（個包装／バラ）は最初に1回選ぶ。
  - 個包装のギフトの値段 ＝ 中身の販売価格（税込）× 個数 ＋（資材＋仕上げの工賃・間接費）÷ 希望原価率 × 税。資材・工賃に利益を乗せるかはチェックで選ぶ（ver.44〜45）。
- 「ほかの商品から材料名／資材名をコピー」（使用量は写さない）。ブロックワークには「ほかの商品から工程をコピー」（ver.42・44）。
- いまの販売価格（手入力）と、計算の値段との差を出す。登録したときと今の計算で値段が違えば、理由を出す（ver.48〜49）。
- 編集中の内容は自動で下書きに残る。ほかの画面へ行っても「← 編集中の〇〇に戻る」で戻れる。

## 原材料マスタ

- 種別（食料品／資材）＋原価の品目（主要材料費・補助材料費・買入部品費・消耗品費など）＋中カテゴリ＋小カテゴリ。チェックした材料をまとめて変えられる。
- 価格を変えて保存すると「価格を更新しますか？」→「はい」で更新日が今月になる。「◯年◯月で更新」ボタン、「更新しない」（`---` 表示）もある。
- 1年以上更新していない材料、または空欄の材料には赤い⚠。「⚠要更新だけ」で絞り込めて、残りの件数も出る。
- 材料名を変えると、原価計算の材料名も変わる。削除するときは、使っている商品の名前を出して確認する。

## レシピ帳

- 1商品1ページ。商品名、説明と写真、参照元、材料（倍数ごとの数字に単位）、焼成（オーブン2台・2段階・湿度・上火・下火・風量・◯分◯秒）、作り方（装飾つき）、メモ。
- 選ぶときはカテゴリ → 商品。コラムのページは「好きな商品のページのあと」に置ける。
- ページカール：スワイプのときだけ。平面だけで描く（短冊は使わない）。約1mm動いたら始まり、指に合わせて動く。払うと速くめくれる（本人が「とてもいい」と言っている）。
- 印刷：保存用（A4／B5・全部の項目）と仕事用（B6・説明と写真なし・裏にメモ）。設定で、用紙・余白・文字の大きさ・行間・項目を変えられる。

## ブロックワーク

- 在庫は、カテゴリごとに折りたたむ。店頭に並べない月の商品は薄く出す。商品ごとに「在庫確認に出す／出さない」を選べる。
- 棚卸しモード（ver.43）：製品・仕掛品は原価で、原材料・資材はマスタの単価で、品目別に年末の在庫金額を出す。年ごとに保存して確定できる。CSV の書き出しと印刷もできる。

## ギフトの組み合わせ（ver.47〜49）

- 金額で作る（ぴったりに近く／目標以下。送料を引ける）か、個数で作る。入れ物はおまかせか指定。
- ギフトの種類：日持ちするギフト（クッキー・焼き菓子）、通常（クッキー・焼き菓子・半生菓子・パウンド・チョコ）。
- 決まり：特注でなければ、メレンゲは1つまで・クッキーは2〜3個など。ギフトに入れない商品にはチェックを付ける。
- 箱に対応する手提げ袋・紙パッキン・リボン・ショップカード（値段には入れない）は、資材の編集画面で箱に結びつける。

## 入力欄・iPad（何度も直したところ）

- 材料名の候補リストで、スクロールしたいときに誤って選ばれる問題は ver.29 でほぼ解決した。リストがスクロール不要なときに、まわりの画面が動かないようにもした。
- 数字の欄は数字のキーボード。小さい浮いた数字パッドは設定で選ぶ（既定はオフ）。
- 数字の欄：選ぶと消える、確定なしでも入る、改行で下の欄へ（ver.45〜49）。文字の欄は消さない（ver.51）。
- キーボードが入力欄にかぶらないように、自動でスクロールする（ver.40）。キーボードが出ていないときは動かさない（ver.51）。
- レシピの編集中は、キーボードを閉じない（ver.39）。
